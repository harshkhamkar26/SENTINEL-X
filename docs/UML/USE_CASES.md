# UML Use Cases

## Actors
- SOC Analyst
- SOC Manager
- Security Administrator
- Incident Responder
- System Administrator
- Data Source / SIEM
- Threat Intelligence Provider
- AI Agent Orchestrator

## Primary Use Cases
1. Authenticate user
2. Configure data source
3. Ingest security events
4. Normalize events
5. Detect suspicious activity
6. Correlate events
7. Create alert/case
8. Investigate case
9. Enrich evidence
10. Assess SOC posture
11. Generate AI explanation
12. Recommend response
13. Approve/reject response
14. Execute approved response
15. Review audit trail
16. Generate report

## Key relationships
- Detection includes event normalization and validation.
- Investigation includes evidence enrichment and AI analysis.
- Response recommendation precedes approval for high-impact actions.
- Execution includes policy validation and audit logging.
- SOC assessment uses detection, case and response metrics.
